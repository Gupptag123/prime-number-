# prime-number-

About the Project

This is a simple Python project that works with text and numbers. It takes a sentence and a number from the user, analyzes the sentence, and checks whether the number is prime.

What It Does

- Counts the total number of words in a sentence.
- Finds the longest word.
- Reverses the sentence.
- Checks whether a number is prime.

Tools Used

Python 3

How to Run

1. Save the code as "text_number_tools.py".
2. Open a terminal in the project folder.
3. Run "python text_number_tools.py".
4. Enter a sentence and a number when prompted.

What I Learned

While making this project, I practiced writing functions, working with strings, taking user input, using loops, and applying conditions in Python.

Conclusion

This project helped me understand how to divide a program into small functions, with each function handling a specific task.
